Asynchronous programming. Multiprocessing
Результати за часом:

Асинхронний код для чисел від 1 до 10 значно швидший, ніж мультипроцесорний. У мультипроцесорній версії на створення процесів витрачається в рази більше часу, ніж на самі обчислення. Асинхронний код працює в одному процесі та одному потоці, тому не має цих накладних витрат (overhead).Для реальних важких обчислень (CPU-bound) більш ефективною є мультипроцесорна реалізація. Вона дозволяє задіяти кілька ядер процесора, тоді як асинхронність працює лише на одному ядрі й не дає реального прискорення для чистих обчислень.
